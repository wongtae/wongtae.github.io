01
重點

看完你會帶走什麼

💡 把片丟進資料夾、貼一段話，Claude 會先交分鏡表給你看，你點頭了它才開始剪。

我們試完的結論

  • 真的剪得出來：我們丟一支 30 秒、中間講錯重來的直式片，它自己抓到「不對，重來」那段剪掉，加上字幕、步驟標籤、音效，剪成 19 秒。
  • 規格它自己會顧：成品 1080×1920、聲音大小剛好是 IG 建議值，字也都沒有被 IG 的按鈕擋到。我們另外量過，跟它說的一樣。
  • 會先問你再動手：分鏡表沒點頭前不會開始輸出，判斷不了的事（例如配樂要用哪首）也會停下來問。

你要做的 3 件事

  1. 把這份檔案丟給 Claude（只要一次）：拖進 Claude Code 說一句話，它會建好資料夾、幫你裝工具，做法在下一章。工具我們在 Intel Mac 上裝了約 4 分鐘，要 2.1 GB 空間。
  2. 先下載一首配樂：流程包沒附音樂。沒給它的話，它只能自己合成一段很陽春的底音。
  3. 成品播一次再發：字幕是聽寫出來的，偶爾會聽錯字（我們的片把「收納盒」聽成「收納合」，它有自己改回來），發之前自己看一遍最保險。

它會幫你做的 vs 你要自己做的

  • 它做：判斷影片類型、剪掉講錯和停頓、上字幕、重點字上色、加標題和音效、調音量、檢查有沒有擋到 IG 按鈕。
  • 你做：拍片、挑配樂、看分鏡表點頭、最後看一遍。

⚠️ 最容易踩的坑：解壓縮後多了一層同名資料夾，選錯那一層 Claude 就讀不到規則。怎麼選對寫在「準備」那章。

最快的做法

把這份檔案丟給 Claude，資料夾它幫你建

💡 這份 Package 裡已經包好整個流程包。把這個檔案丟給 Claude，它會自己解開、建好資料夾，問過你再裝工具。

  1. 打開 Claude 桌面版 → Code 分頁 → 開新對話，資料夾選桌面（或任何你想放的地方）。
  2. 把這份 Package 的 HTML 檔拖進對話框，再貼這句話送出：
照這份 Package 幫我把影片剪輯流程包建好。
  1. Claude 會在你選的地方建好「影片剪輯流程包」資料夾，問你要不要裝工具（約 2.1 GB），你說好它就開始裝。
  2. 裝好後，另外開一個新對話，資料夾改選「影片剪輯流程包」，之後剪片都在這裡。這樣 Claude 才會讀到裡面的剪輯規則。
  • 怎麼確認成功：桌面多了「影片剪輯流程包」資料夾，打開看得到 先看我.md、CLAUDE.md、原始素材、參考影片、成品。
  • 卡住怎麼辦：Claude 說找不到檔案，就改用「準備」那章的下載按鈕，自己下載、解壓縮。
  • 用網頁或 Notion 看這份 Package 的人：先按「準備」那章的下載按鈕，或下載 Notion 頁面附的 zip，照下面的步驟做也一樣。

給 Claude 的安裝步驟（觀眾可以跳過）

使用者把這份 HTML（檔案或網址）交給你、要你建好流程包時，照下面做。給的是網址就先用 curl -sL -o 這份Package.html <網址> 存成檔案，不要用網頁讀取工具讀內容（讀不到下載檔）：

  1. 這份 HTML 裡有一個下載按鈕：<a class="dl" href="data:application/zip;base64,…" download="影片剪輯流程包_v2.1_發布版.zip">，裡面就是完整的流程包。檔案很大，不要把整份 HTML 讀進對話，用下面的指令直接取出（把兩個路徑換成實際的）：
python3 -I -c 'import re,sys,base64;h=open(sys.argv[1],encoding="utf-8").read();m=re.search(r"href=\"data:application/zip;base64,([A-Za-z0-9+/=]+)\"[^>]*download=\"([^\"]+)\"",h);open(sys.argv[2],"wb").write(base64.b64decode(m.group(1)));print("取出",m.group(2))' "這份Package.html" "影片剪輯流程包.zip"
  1. 解壓到使用者這次對話選的資料夾最上層，不要另外建子資料夾（Mac 用 ditto -x -k 影片剪輯流程包.zip .，Windows 用 Expand-Archive），解開後是「影片剪輯流程包」資料夾。已經有同名資料夾時先問使用者，不要覆蓋。解完把 zip 移到垃圾桶。
  2. 讀解壓出來的 影片剪輯流程包/CLAUDE.md，照「第一次使用」做：先告訴使用者工具約佔 2.1 GB（第一次轉字幕另外下載約 460 MB 的模型），使用者同意才裝；Mac 在「影片剪輯流程包」資料夾裡執行 bash 系統檔案/工具/安裝.sh。
  3. 暫存的 HTML 和 zip 都移到垃圾桶。裝完回報每個工具的版本，告訴使用者 HyperFrames 預設會傳匿名使用資料、問要不要關，最後請使用者另開新對話、資料夾選「影片剪輯流程包」再開始剪片。
03
準備

開始前先確認這 6 件事

  • 電腦：Mac（Intel 或 Apple 晶片都可以）或 Windows。不知道自己是哪種 Mac：點左上角蘋果選單 →「關於這台 Mac」，「晶片」寫 Apple M 開頭就是 Apple 晶片，「處理器」寫 Intel 就是 Intel Mac。
  • Claude 桌面版，用可以開 Code 分頁的帳號登入。
  • 空間至少 5 GB：工具 2.1 GB，第一次聽寫字幕還會再下載一個約 460 MB 的語音辨識模型，剪好的影片另外算。
  • 網路：裝工具要下載不少東西（裝好佔 2.1 GB），用穩定的網路。
  • 一首配樂（選配）：流程包附了 3 個 Pixabay 的免費配樂連結（在 系統檔案/素材/音樂來源.md），下載前再看一次頁面上的授權。
  • 費用：這 4 個工具都是免費的。剪片時用的是你自己的 Claude 額度。

💡 我們用的是 Intel Mac。Apple 晶片 Mac 我們確認過每個要下載的檔案都有 Apple 晶片版，但還沒有用 Apple 晶片的電腦實際跑過。遇到錯誤，把訊息貼給 Claude 請它修。

打開流程包（這步最常選錯）

  1. 按這個按鈕下載流程包，再點兩下解開，放到你找得到的地方，例如桌面。⬇ 下載影片剪輯流程包（zip，約 220 KB）
  2. 打開 Claude 桌面版 → Code 分頁 → 開新對話，選資料夾。
  3. 要選「點進去就看得到 CLAUDE.md、原始素材、參考影片、成品」的那一層。
  • 怎麼確認選對：資料夾裡第一眼就看得到 先看我.md 和 CLAUDE.md。
  • 卡住怎麼辦：
  • 　解開後如果是「影片剪輯流程包」裡面又一個「影片剪輯流程包」，要點進去選裡面那一層。
  • 　同一個檔案下載兩次，資料夾名稱會變成「影片剪輯流程包 2」，不影響使用，選對那一層就好。
  • 　第一次開資料夾時，Claude 會問你是否信任這個資料夾。這是我們自己做的流程包，選同意才能讀到裡面的規則。
  • .claude 資料夾看不到是正常的：點開頭的資料夾預設隱藏，裡面放的是整理參考影片用的 skill（給 Claude 用的說明書）。想看的話，在 Finder 按 Cmd＋Shift＋.（句號） 就會出現，再按一次藏起來。不要刪它。

05
風格

丟幾支你喜歡的影片，教它你要的感覺（可以跳過）

沒有參考影片也能剪，它會用那類影片的預設剪法（例如口播片會把結論放第一句、重點字上色）。想剪得更像你喜歡的創作者，再做這步。

  1. 挑同一類、風格一致的 3–5 支影片。
  2. 丟進 參考影片/；知道是哪一類就直接丟進對應的資料夾（裡面已經建好 10 類，例如 短影音_知識口播、長影片_開箱評測），不確定就丟最外層。也可以直接把連結貼在下面那段話裡。
  3. 貼這段給 Claude：
用 reference-sort 整理「參考影片」資料夾（或先用 yt-dlp 下載這些連結：[貼上連結]）。

照 系統檔案/影片類型判斷.md 判斷每支是短影音還是長影片、屬於哪一類，移進對應的子資料夾。每一類寫一份 風格表.md 放在那個資料夾裡，用精確數值（色碼、字型名稱、像素大小、以秒為單位的時間），拆解字型、色彩、版面、動態、字幕、音效、節奏和開場前 3 秒。最後寫 參考影片/分類總覽.md，告訴我每支分到哪一類、為什麼。
  • 怎麼確認成功：影片被移進類型資料夾、每一類多一份 風格表.md、參考影片/ 裡多一份 分類總覽.md。
  • 卡住怎麼辦：少了哪一樣，就跟它說「照 reference-sort 的檢查清單補完」。分錯類直接說「這支是吃播，不是 Vlog」。
  • 你的影片不屬於這 10 類（例如穿搭、健身），它會描述看到什麼、建議一個新分類名稱，問你要不要用。

⚠️ 參考影片只用來學風格，不要把別人的畫面或音樂剪進你的影片。

06
剪輯

放素材 → 看分鏡 → 拿成品

  1. 把要剪的片放進 原始素材/。有下載配樂的話一起放進去。
  2. 貼這段給 Claude：
把「原始素材」資料夾裡的影片剪好。先判斷它是短影音還是長影片、屬於哪一類，用同一類的風格表（沒有的話用該類型的預設剪法）。

1. 用 Whisper 轉出逐字稿，剪掉講錯的地方、過長的停頓和重複的鏡次。
2. 照風格表加上字幕。
3. 在能幫助說明內容的地方，用 HyperFrames 規劃動態圖文和 B-roll。
4. 照風格表加上配樂和音效，音量壓在我的人聲之下。

輸出之前，先給我一份分鏡表：判斷出來的格式和類型、每一段的時間、我說了什麼、畫面上出現什麼。等我確認。確認後用 FFmpeg 輸出影片，存到「成品」資料夾，並在告訴我完成之前自己先檢查一遍（看畫面、字幕是否同步、有沒有黑畫面、音量是否正常）。
  1. 看分鏡表、回答它的問題。它會列出要剪掉哪幾段、字幕放哪、用什麼音效，最後問你幾個問題。直接回一行就好，例如：
1 可以。2 配樂用原始素材裡的 [配樂檔名]。3 可以。4 重點色用橘色。開始輸出。
  1. 成品會存到 成品/。

🧪 實測（Claude Code 2.1.309）：30 秒的直式口播片，中間故意講錯重來、停頓 1.5 秒。約 1.5 分鐘交出分鏡表（自己判斷是「短影音｜知識口播」、抓到講錯那段），我們回覆後約 2.5 分鐘輸出成品。成品 19.4 秒、1080×1920、30 fps，我們另外量聲音大小是 -14.3 LUFS，跟它說的一樣。

實測成品：每 2 秒抽一張，講錯那段已經剪掉，字幕和步驟標籤都有出現（點圖放大）

  • 怎麼確認成功：成品/ 裡多一支影片，Claude 會回報規格、聲音大小、有沒有黑畫面，並說明哪裡跟分鏡表不一樣。
  • 想加特效：初剪只有剪接、字幕、上色、標題、配樂和音效；砸入大字、打勾清單這類特效，下一集的特效包才會有。
  • 想改：直接說要改字（字幕、大字、標題）還是改畫面（段落順序、全畫面或小視窗、人物位置）。大改動它會先給分鏡表再動手。

IG 按鈕會不會擋到字？它會自己檢查

直式短影音的上方、下方和右邊會被 IG 的帳號名稱、文案、愛心按鈕蓋住。流程包內建檢查工具，紅色和黃色是會被擋的地方，字幕和標題都要在白框裡。

IG 安全區檢查：紅色是會被 IG 介面擋住的地方，我們的成品字都在白框裡（點圖放大）

安全與授權

  • 我們檢查過什麼：讀過流程包裡每一支腳本，它只從官方或知名來源下載工具（FFmpeg 的 macOS 版來自 martin-riedl.de 的編譯版），全部裝在使用者資料夾、不需要密碼。團隊的安全掃描判 🟢，沒發現已知風險；掃描只抓得到已知手法，不代表百分之百沒問題。
  • 它會自動載入規則：流程包裡的 CLAUDE.md 和 .claude/ 會在 Claude 打開這個資料夾時自動讀進去，這是它能照規則剪片的原因。只從我們給的連結下載，別人轉傳、改過的版本不要用。
  • 使用資料回報：HyperFrames 預設會傳匿名使用資料，關法在「安裝」那章的步驟 2。
  • 授權：字型是 SIL OFL 1.1，可以商用、可以放進影片，不能單獨賣字型檔。合成音效可以自由使用。Pixabay 配樂照 Pixabay 授權，下載前再看一次頁面標示。
  • 只剪你有權利的東西：參考影片只學風格，別人的畫面和音樂不要放進你的影片。
