01
重點

看完你會帶走什麼

💡 它能幫你翻最近 30 天的社群討論，照按讚、留言排好；先只開免費來源，設定時讀登入資料那幾題不確定就按不要。

它幫你省掉什麼

  • 不用每個平台滑一遍：在 Claude Code 打 /last30days 主題，它去翻 Reddit、YouTube、科技論壇這些來源最近 30 天的討論。
  • 不用自己判斷誰在亂喊：官方說它照按讚、留言這些真人反應打分數，整理成重點，並標出每則的出處。
  • 基本來源不用錢：官方說 Reddit（含留言）、Hacker News（科技人常逛的論壇）、GitHub 不用申請任何帳號就能用；YouTube 要另外裝一個免費的小工具。

裝之前先知道 3 件事

  1. 電腦要有 Python 3.12 以上：Python 是讓電腦跑這個工具的程式語言。Mac 內建的是 3.9，不夠，它會直接停下來告訴你怎麼裝。
  2. 設定時有幾題會問你要不要給權限：要不要讀瀏覽器裡 X、Reddit 的登入資料、要不要自動裝一堆小工具。不確定就按不要，之後還能再開。每題怎麼按看「② 第一次設定每題怎麼按」。
  3. 不是每個平台都免費：TikTok、IG、Threads 要另外申請 ScrapeCreators（一家幫你抓社群資料的服務），官方說前 10,000 次免費，之後用多少付多少。

我們檢查過什麼

  • 安全掃描加人工複核判 🟡：可以用，但要會設定。掃描抓到的「後門」「忽略指令」字樣都在作者自己的測試檔裡，不會裝到你電腦；它真的會做的是「經你同意後讀瀏覽器登入資料」和「自動裝外部小工具」。
  • 測試官在隔離的測試資料夾跑過：Python 3.9 會被擋並印出裝法；換成 3.12 後，「只檢查、不搜尋」模式顯示可以開始，瀏覽器登入資料預設是關的。
  • 它執行時不需要另外裝第三方套件，只用 Python 內建功能；外掛設定裡沒有自動觸發的動作。
  • 測試官另外照官方找 Python 的方法模擬過：電腦裡有 3.12，就算查版本的 python3 --version 還是顯示 3.9，它也會自己用 3.12。
  • 測試官也確認過：沒有 yt-dlp 時可用來源裡沒有 YouTube，自己裝好 yt-dlp 後 YouTube 就出現，不用重跑設定。

⚠️ 最容易踩的坑：官方 README 下面的安裝表格少了一行 /plugin install last30days，照表格做會裝不起來。完整步驟看「① Mac／Windows 安裝步驟」。

02
先懂

它是什麼

skill（技能包）就是給 AI 的工作說明書。last30days 裝進 Claude Code（一個會幫你在電腦上操作的 AI 助手）之後，你打 /last30days 加一個主題，Claude 就照這套流程去各個網站搜、排序、整理。

  • 沒有它：IG、YouTube、論壇一個一個開，滑完還要自己判斷哪則真的有人在討論。
  • 有它：打一個主題，它翻最近 30 天的討論，照按讚、留言、新不新打分數，整理成重點，標出處。
  • 結果存在哪：官方說預設存在「文件」裡的 Last30Days 資料夾，一次搜尋一份文字檔，之後可以叫它查以前搜過的。
  • 授權：MIT，可以免費用、可以商用，保留授權聲明就好。作者本人維護，有寫資安說明（SECURITY.md）。

哪些來源免費、哪些要錢（官方說法）

  • 不用申請就能用：Reddit（含留言）、Hacker News、Polymarket（預測市場）、GitHub
  • 免費，但要另外裝工具：YouTube（要裝 yt-dlp，一個免費的影片資訊下載工具）
  • 要讀你的登入資料或申請金鑰：X（三選一：X 官方金鑰、讀你瀏覽器裡已登入 x.com 的資料、Xquik 或 xAI 金鑰）
  • 要申請 ScrapeCreators：TikTok、Instagram、Threads、Pinterest、LinkedIn、YouTube 留言；前 10,000 次免費，之後用多少付多少
  • 其他選用：Brave 網頁搜尋每月 2,000 次免費；Perplexity 要付費
  • 沒有的：PTT、Dcard 不在它的來源名單裡

「金鑰」（API key）就是讓程式用你的名義連上別家服務的通行碼，申請了就可能被計費，不用的話不必申請。

03
準備

開始前要有的東西

  • Claude Code（已經裝好、能打字跟它聊）
  • Python 3.12 以上（下一章教你查、教你裝）
  • Mac 要裝 Python 的話：官方建議用 Homebrew（Mac 上裝軟體的免費工具）
  • 官方說：電腦裡如果已經有 uv（另一個裝 Python 的工具），它會自己下載一份 3.12（約 28MB），不用另外裝；沒聽過 uv 就照下一章裝 Python
  • 想搜 YouTube：yt-dlp（免費，下一章有裝法）
  • 費用：用免費來源是 0 元；開 TikTok、IG 這類來源，超過免費額度要付費
  • 以下指令都是 Mac 終端機的寫法；終端機在「應用程式 → 工具程式 → 終端機」

Windows 可以用嗎？

官方有寫 Windows 的 Python 裝法：

winget install Python.Python.3.12

另外官方和工具測試寫到的 Windows 差別：

  • 報告預設存在 C:\Users\<你的使用者名稱>\Documents\Last30Days\。
  • 讀瀏覽器登入資料這個功能，在 Windows 只讀 Firefox。
  • Claude Desktop（桌面 App 版）官方寫 Windows 版還沒支援；這份教的是 Claude Code 版。
  • 裝 yt-dlp 的 brew 指令是 Mac 用的。官方寫 Windows 改用下面這行裝，而且提醒它可能裝到不在 PATH（系統找指令的路徑）裡的資料夾；裝完 YouTube 還是沒開的話，要把那個資料夾加進 PATH。
pip install yt-dlp

我們用的是 Mac，Windows 這段照官方文件整理，還沒自己試過，照做前請先小心確認。

①

Mac／Windows 安裝步驟

  1. 先查 Python 版本：打開終端機（Windows 打開「命令提示字元」或 PowerShell），輸入：
python3 --version

- 怎麼確認成功：看到 Python 3.12.x 或更新的數字就對了，直接跳到步驟 3。Windows 如果說找不到 python3，改打 python --version。

- 卡住怎麼辦：看到 Python 3.9.6（Mac 內建）或更舊，先再打一次 python3.12 --version；有看到 Python 3.12.x 代表你以前裝過，直接跳到步驟 3，沒有才做步驟 2。

  1. 版本不夠就裝 3.12（這兩行是工具自己印出來的官方建議）：

Mac：

brew install python@3.12

Windows：

winget install Python.Python.3.12

- 怎麼確認成功：關掉終端機重開，打下面這行，看到 Python 3.12.x 就對了。這時候打 python3 --version 可能還是顯示 3.9，沒關係，last30days 會自己去找 3.12。Windows 打 python --version 或 py -3.12 --version。

python3.12 --version

- 卡住怎麼辦：Mac 出現 command not found: brew，代表電腦沒有 Homebrew；可以改到 Python 官網（python.org）下載 3.12 以上的 macOS 安裝檔來裝。從官網裝的 3.12 它一樣找得到，就算 python3 --version 還是顯示 3.9 也沒關係，用上面那行 python3.12 --version 確認就好。

  1. 打開 Claude Code，在你平常工作的資料夾開。第一次在某個資料夾開，Claude Code 會問要不要信任這個資料夾：只在你自己的工作資料夾按信任，不要在剛下載的陌生資料夾裡開。
  1. 加入作者的外掛市集，在 Claude Code 裡輸入：
/plugin marketplace add mvanhorn/last30days-skill
  1. 安裝外掛（README 下面的表格漏了這行，一定要打）：
/plugin install last30days

- 怎麼確認成功：做下一步，第一次打 /last30days 會跳出設定精靈，就代表裝好了。

- 卡住怎麼辦：打 /last30days 沒反應，多半是漏了這一步，再打一次上面這行。

  1. 第一次搜尋：打 /last30days 加一個主題，它會先跳出設定精靈。每一題怎麼按，照「② 第一次設定每題怎麼按」。
/last30days 露營新手最常問的問題
  1. 想先看它會讀寫哪些地方、不真的搜尋：跟 Claude 說這句，它會跑「只檢查」模式，列出會讀什麼、寫到哪個資料夾、會連哪些來源。
用 last30days 的 --preflight 檢查一次，告訴我它會讀寫哪些地方、連哪些網站
  1. 搜尋時 Claude 會問權限：它要執行 last30days 的指令時會問你，看清楚是 last30days 的指令再允許。
  1. 用完不要了： - 在 Claude Code 打 /plugin，打開外掛管理，把 last30days 移除。 - 步驟 4 加入的外掛市集（名字是 last30days-skill）也一起移除：一樣在 /plugin 裡找管理市集的地方。 - 刪掉它存資料的地方：「文件」裡的 Last30Days、家目錄裡的 .config/last30days 和 .local/share/last30days。.config、.local 是隱藏資料夾，Finder 要在家目錄按 Cmd＋Shift＋. 才看得到；或在終端機打 ls -a ~ 確認。 - 選過「Auto setup」的話，它還自己裝了 yt-dlp（Mac 用 brew uninstall yt-dlp 移除）和放在 .local/bin 裡的 4 個小工具：digg-pp-cli、arxiv-pp-cli、techmeme-pp-cli、yahoo-finance-pp-cli（查股價用的），要另外刪。這些小工具要電腦有 Node.js 才裝得上，沒有就不會出現。 - 它沒有一個指令就全部移除的功能，上面這幾個地方要自己一個一個刪。

第一次設定每題怎麼按

第一次打 /last30days，會跳出英文的設定精靈。底下照「最少風險」排，不確定就照推薦按。

我們推薦的按法

  • 第一題「How would you like to set up?」，有三個選項：

- Auto setup (~30s)：自動設定，會讀登入資料、裝一批小工具

- Manual setup：自己一個個設，新手不用選

- Skip for now：先跳過 ← 推薦選這個

- 為什麼：官方原文寫「Auto setup installs the free CLIs either way」，就算你拒絕讀登入資料，自動設定也會用 Homebrew 裝 yt-dlp，再用作者另一個套件裝一批小工具到 ~/.local/bin。那個套件不在這個專案裡，我們沒有審過。

- 選 Skip for now：什麼都不裝，先用 Reddit（含留言）、Hacker News、Polymarket、GitHub、網頁這些免費來源。

  • 搜完它還會再問一次：要不要加 TikTok、IG（ScrapeCreators） → 一樣按最後的 Skip for now。

- 選了先跳過，不代表後面什麼都不問。官方流程是：先幫你搜完、給結果，接著問這一題，因為之後就不會再問。

- 四個選項：ScrapeCreators via GitHub (recommended - most free calls)、Open scrapecreators.com (Google sign-in)、I have a key、Skip for now。

- 第一個寫著 recommended（推薦），不代表你要選；選了會打開 GitHub 頁面、把代碼複製到剪貼簿。沒打算付費就按最後的 Skip for now。

  • 想搜 YouTube：自己在終端機裝 yt-dlp（官方寫的裝法；Windows 改用 pip install yt-dlp，見「準備」章）：
brew install yt-dlp

- 裝好之後不用重跑設定，它會自己把 YouTube 加進可用來源（測試官確認過：沒裝時來源清單沒有 YouTube，裝好就出現）。

如果你選了 Auto setup，後面幾題這樣按

  1. 要不要讀瀏覽器裡 X 的登入資料（cookie）（題目開頭是「Auto setup installs the free CLIs either way … Include X?」）→ 選 Skip X - just the CLIs。 - 三個選項：Yes - X cookies + all CLIs、Skip X - just the CLIs、xAI API key for X instead。 - cookie 是瀏覽器記住你「已經登入」的小檔案。同意的話，它會從瀏覽器讀出 X 的登入資料，拿去搜 X。程式只拿 x.com 的那兩個值，只送回 x.com；但等於讓一個工具拿著你的登入狀態，不確定就不要。 - Mac 用 Chrome 這類瀏覽器時，讀登入資料會跳出系統的鑰匙圈視窗問你，不想給就不要允許。
  2. 如果接著問要不要用 Reddit 登入資料 → 選 No - keep Reddit logged out。 - 另一個選項是 Yes - use my Reddit login。這題官方自己寫「may breach Reddit's terms」（可能違反 Reddit 的使用條款）。不登入也能搜 Reddit。 - 補充：官方資安說明（SECURITY.md）的 cookie 段只寫了 X，沒寫 Reddit 這段，文件比程式碼舊。
  3. 要不要填 ScrapeCreators 金鑰（TikTok、IG、Threads 要用）→ 沒打算付費就選 Skip for now。 - 選項和上面「先跳過」那段一樣，第一個寫著 recommended，不用理它，按最後的 Skip for now。 - 官方說前 10,000 次免費，之後用多少付多少；而且填了之後，這把金鑰也會拿去補 Reddit、YouTube 的搜尋，用量會比你想的快。
  4. Grok 路線（用 xAI 的 Grok 搜 X） → 不要開。 - 設定精靈不會主動推薦它，要手動設定才會走。但這條路線會用「跳過權限詢問」的模式跑 Grok 的程式，等於不再一步一步問你。

設定之外，電腦裡本來就有的東西

  • 你的電腦裡如果設過 OpenAI、Gemini、xAI、OpenRouter 的金鑰（就算是為了別的工具設的），它每次搜尋都會把主題和搜到的片段送去那家重新排序：會花那家的錢，主題也會送出去。不想這樣，就不要在同一台電腦的環境裡留著這些金鑰。
  • 電腦有登入 GitHub 指令工具（gh）：它會拿來搜 GitHub。

10 個做選題的問法

在 Claude Code 裡直接貼，把 [括號] 換成你的主題。句型照官方範例（人名、產品、A vs B、「最近什麼最紅」）改成中文。

找題目

/last30days [你的領域] 最近大家在討論什麼
/last30days [你的領域] 新手最常問的問題
/last30days [你的領域] 大家最常抱怨什麼
/last30days 最近 AI 工具圈什麼最紅

比較、評價

/last30days [產品 A] vs [產品 B] vs [產品 C]
/last30days [某個工具或產品] 真實使用心得
/last30days [某個人或品牌]

開店、做生意

/last30days [你賣的東西] 大家買之前最在意什麼

搜完接著問 Claude（這兩句是跟 Claude 聊，不會再去搜）

把上面的結果整理成 5 個短影音題目，每個附一句開場和原文出處
上面哪些討論最多人回應？挑 3 個，用繁體中文各寫一段重點

查以前搜過的

官方範例有「search my library」的用法，可以翻以前存下來的結果：

/last30days search my library for [主題]

中文小提醒

  • 官方範例的主題都是英文；它的來源大多是英文社群，PTT、Dcard 不在名單裡。
  • 官方說：搜中文主題時，它會先提醒你英文來源可能比較少，並說 X 和 YouTube 是最能補中文內容的來源。
  • 中文主題結果太少時，換成英文關鍵字再搜一次（例：「露營新手」改成 camping beginner）。
  • 要結果用中文看，在句子最後加「用繁體中文整理」。

常見問題

卡住先看這裡

  • 要付錢嗎？ 只用 Reddit、Hacker News、Polymarket、GitHub、YouTube 是 0 元。開 TikTok、IG、Threads 要申請 ScrapeCreators，前 10,000 次免費，之後付費；Perplexity 要付費。
  • 打 /last30days 沒反應？ 多半是漏了 /plugin install last30days，回去做「① Mac／Windows 安裝步驟」步驟 5。
  • 跑到一半說要 Python 3.12？ 照「① Mac／Windows 安裝步驟」步驟 1、2 裝好，重開終端機和 Claude Code 再試。
  • 結果是 0 筆？ 它自己會註明「來源失敗不代表沒有討論」。可能是網路連不上那個來源，也可能是中文主題討論少，換英文關鍵字試試。
  • 資料存在哪？ 「文件」裡的 Last30Days、家目錄的 .config/last30days、.local/share/last30days（隱藏資料夾，Finder 按 Cmd＋Shift＋. 才看得到）。
  • 會不會自己更新？ 會。用外掛市集裝的版本會自動更新，所以之後的版本我們沒有檢查過。
08
安全

用之前要知道的事

  • 讀登入資料要你同意才會做：它能讀瀏覽器裡 X、Reddit 的登入資料（cookie），預設是關的，設定時同意才開。我們看過程式碼：只挑 x.com、reddit.com 那幾個值，只送回 x.com、reddit.com。不確定就不要開。
  • 你的主題會送到每個你開的來源：Reddit、YouTube、GitHub 這些搜尋網站都會收到你搜的主題；電腦裡有 OpenAI 等金鑰時，主題和片段也會送去那家。官方說除此之外不會送出資料，「No tracking. No analytics.」（不追蹤、不做使用統計）。不要搜公司機密或客戶名字。
  • 它會自動裝東西、自己更新：Auto setup 會裝 yt-dlp 和作者另一個套件的小工具（我們沒審過）；外掛市集版會自動更新，我們檢查的是 2026-11-18 的版本。
  • 不要開 Grok 路線：那條路線會用跳過權限詢問的模式跑別的程式。
