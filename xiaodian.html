01
重點

看完你會帶走什麼

💡 這包 skill 免費拿得到，但要「只裝 skill、叫它講繁中、自己截地圖前三名」，它才幫得上台灣小店。

它幫你省掉什麼

  • 不用自己猜輸在哪：官方說 google-business-profile 會拿你的 Google 商家檔案跟地圖前三名比，再寫一個月的商家貼文。
  • 評論回覆不用從零想：官方說 reviews 會寫老闆回覆，也會設計服務後請客人留評論的做法。
  • 不用先付錢：官方寫明每個 skill 不用付費工具也能跑；API key（讓程式連上別家服務的通行碼）全部是選用。

裝之前先知道 3 件事

  1. 只裝 skill 資料夾：照「② 只裝 skill 的安全安裝步驟」做，不要用 plugin（外掛）安裝。plugin 版會多掛一個 hook（自動攔截的掛鉤），每次 AI 寫檔、跑指令都會被它檢查一遍。
  2. 第一句就叫它講繁中：它預設是英文、範例是美國店家，沒有語言設定。「③ 叫它講繁中和台灣用語的說法」有整段可以照抄。
  3. 地圖前三名要你自己截圖：skill 文件自己寫明網頁搜尋通常抓不到地圖結果，免費做法是你用手機搜尋、截圖給它。

我們檢查過什麼

  • 安全掃描判 🟡：沒發現已知的惡意手法，要注意的是 plugin 掛鉤、選用的 API key 會把資料送到第三方。
  • 只複製 skills 資料夾的裝法，在隔離的測試資料夾裡照步驟裝成功，32 個資料夾都在，.claude 裡只有 skills，沒有掛鉤和設定檔。
  • AI 寫出來的比較、回覆和貼文都是草稿，送出前一定要自己看過。

⚠️ 最容易踩的坑：照 README 第一個看到的指令用 plugin 裝，或把 API key 一次填滿。詳細在「② 只裝 skill 的安全安裝步驟」和「安全與授權」。

02
先懂

它是什麼

skill 是一份教 AI 照步驟做事的說明書，放進 Claude Code（Anthropic 出的、在終端機裡用的 AI 助手）的 .claude/skills/ 資料夾，打 /skill 名稱 就能叫出來，AI 也會在用得到時自己拿出來用（官方文件：Skills）。

  • 沒有它：你跟 AI 說「幫我做行銷」，它給你一份通用建議，每家店都一樣。
  • 有它：先跑 /start-here，它讀你的網站和評論、寫出你的品牌檔（店的語氣、客人、賣點），之後每個 skill 都照這份品牌檔寫。
  • 官方說：32 個 skill，分成被找到（Google 商家、在地頁面、SEO）、被選上（評論、首頁）、接到電話（廣告）、回頭客（電子報）、接案（找在地客戶）、自己的社群貼文（X 和 LinkedIn）。
  • 授權：MIT，可以用在自己的店、客戶或產品。
03
準備

開始前確認這 5 件事

  • 一台 Mac（下面的指令都是 Mac 終端機寫法；Windows 看下面的說明）
  • 已經裝好、能登入的 Claude Code
  • 你的店的網站或粉專網址、最近的 Google 評論
  • 手機：搜尋「[你的行業] [你的地區]」，把地圖前三名的商家頁截圖
  • 費用：skill 本身 0 元；Claude Code 照你自己的方案計費；API key 先全部不填

用 Windows 的話

官方 README 沒有分作業系統，也沒有寫 Windows 裝法。下一章的 mkdir、cp、ls 是 Mac 終端機的寫法，Windows 不能直接照抄。Claude Code 官方文件只寫了 skill 要放在專案的 .claude/skills/<skill名稱>/ 資料夾，沒有另外寫 Windows 的步驟。我們用的是 Mac，Windows 沒有自己試過，要裝請先小心確認。

04

② 只裝 skill 的安全安裝步驟

這個裝法只把 skill 放進一個資料夾，只有在這個資料夾開 Claude Code 才會用到，不影響你其他專案。

  1. （必做）確認是本尊：在 GitHub 搜尋 boringmarketer/boring-marketing-skills，確認作者帳號是 boringmarketer、授權寫 MIT。名字很像但帳號不同的，不要下載。
  2. 在專案頁按綠色「Code」→「Download ZIP」，解壓縮。以下假設解到「下載」資料夾，名稱是 boring-marketing-skills-main。 - 注意：GitHub 的 ZIP 解開後，資料夾名稱會多出 -main；下載兩次可能變成 boring-marketing-skills-main 2。指令裡的名稱要跟你「下載」資料夾裡實際看到的一樣。
  3. 建一個放你店資料的資料夾和 skill 資料夾（~/my-shop 是範例，可以換成你想要的名字，後面指令也要一起換）：
mkdir -p ~/my-shop/.claude/skills

- .claude 是點開頭的隱藏資料夾，Finder 裡預設看不到。想在 Finder 看到，按 Cmd＋Shift＋.（句點）；或在終端機輸入 ls -a ~/my-shop。

  1. 只複製 skills 裡的 32 個資料夾（不要複製 .claude-plugin、automations）：
cp -R ~/Downloads/boring-marketing-skills-main/skills/. ~/my-shop/.claude/skills/

- 怎麼確認成功：輸入下面這行，看到 32 就對了。

ls ~/my-shop/.claude/skills | wc -l

- 卡住怎麼辦：顯示「No such file or directory」，通常是解壓縮的資料夾名稱或位置不一樣，打開「下載」資料夾看實際名稱，改掉指令裡的 boring-marketing-skills-main。

- 看到的數字是 1：代表指令最後的 /. 漏掉了，skill 多包了一層，Claude Code 會找不到。把整行照上面重打一次。

  1. 進資料夾開 Claude Code：
cd ~/my-shop && claude

- 第一次在這個資料夾開 Claude Code，會先問你信不信任這個資料夾，這是你自己建的資料夾，選 Yes。

  1. 輸入第一句（「③ 叫它講繁中和台灣用語的說法」有完整版）：
/start-here 你的店名
全程用繁體中文、台灣用語回答，範例換成台灣的店。
  1. （必做）不要用這三種： - 不要用 /plugin marketplace add …、/plugin install …：會掛上攔截每次寫檔和跑指令的 hook。 - 不要跑專案裡的 _system/scripts/install.sh：它會裝進 ~/.claude/skills，你電腦上所有專案都會被影響。

不想用了怎麼移除

這個裝法只動到 ~/my-shop/.claude/skills/ 這個資料夾。不想用了，把它刪掉就好；~/my-shop 裡如果有它幫你寫的品牌檔，要不要留你自己決定。下載的 ZIP 和解開的資料夾在「下載」裡，也可以一起刪。

① 5 個指令中文對照表

除了 /start-here，下面的叫法都是照官方說明寫的範本，方括號 [ ] 裡的字換成你自己的。每一句後面都可以加「全程用繁體中文、台灣用語」。

1. /start-here｜第一次一定先跑

  • 白話：讀你的網站和評論，寫出品牌檔，再告訴你下一步用哪個 skill。
/start-here [你的店名]
我的網站是 [網址]，Google 商家名稱是 [名稱]。全程用繁體中文、台灣用語回答。

2. /google-business-profile｜想知道地圖上輸給誰

  • 白話：拿你的 Google 商家檔案跟地圖前三名比，列出該改的地方，寫一個月的商家貼文。
/google-business-profile
我附上用手機搜尋「[你的行業] [地區]」的地圖前三名截圖。請拿我的商家檔案跟這三家逐項比，列出我少了什麼、先改哪 3 個，最後寫一個月的商家貼文。

3. /reviews｜評論不知道怎麼回

  • 白話：幫你寫老闆回覆，設計服務完請客人留評論的說法。
/reviews
以下是我最近 10 則 Google 評論。每則寫一段老闆回覆：口氣像台灣小店老闆、不超過 80 字；負評先道歉再說明怎麼改善，不要承諾做不到的事。

4. /social-content｜X、LinkedIn 貼文想不出來

  • 白話：照你自己表現最好的貼文口氣，寫新的 X（原本的推特）和 LinkedIn（職場社群）貼文。
  • 注意：官方說明寫的是 X 和 LinkedIn，沒有寫 IG／FB。Google 商家貼文請用上面的 /google-business-profile。
  • 官方建議先貼 10 到 30 則你自己表現最好的舊貼文，沒有舊貼文就給它 3 到 5 個真實的數字或成果。
/social-content
這是我過去表現最好的 10 則貼文：[貼上文字]。照這個口氣寫 4 週、每週 2 則的 X 和 LinkedIn 貼文，不要用誇大效果的字眼。

5. /competitive-intel｜想知道對手被客人抱怨什麼

  • 白話：看搜尋時最先出現的幾家，整理他們的客人在抱怨什麼。
/competitive-intel
幫我看搜尋「[你的行業] [地區]」時最先出現的幾家，整理他們的客人最常抱怨什麼，我可以怎麼做得不一樣。

③ 叫它講繁中和台灣用語的說法

skill 本身沒有語言設定，要你自己講清楚。第一次跑 /start-here 時整段貼上：

全程用繁體中文、台灣用語回答。
範例換成台灣的店，金額用新台幣，地址和電話用台灣格式。
不要用簡體字和中國用語，例如：視頻→影片、質量→品質、信息→訊息、用戶→使用者。
請把「一律用繁體中文、台灣用語」寫進品牌檔的語氣規則。

如果中途又跑出英文，直接說：

剛剛那段改成繁體中文、台灣用語，口氣像在跟熟客講話。

常見問題

卡住先看這裡

  • 問：一定要填 API key 嗎？

- 答：不用。官方寫明每個 skill 不用付費工具也能跑，key 全部是選用。

  • 問：它可以自己抓 Google 地圖前三名嗎？

- 答：免費做法不行。skill 文件寫明網頁搜尋通常抓不到地圖結果，要你用手機搜尋、截圖給它。

  • 問：為什麼它一直講英文？

- 答：它的內容和範例都是英文、美國店家，沒有語言設定。照「③ 叫它講繁中和台灣用語的說法」在第一句講清楚。

  • 問：裝在哪裡比較好？

- 答：裝在專案資料夾的 .claude/skills/（「② 只裝 skill 的安全安裝步驟」的做法），只有在那個資料夾開 Claude Code 才會用到。

  • 問：Finder 裡找不到 .claude 資料夾？

- 答：點開頭的資料夾是隱藏的，按 Cmd＋Shift＋.（句點）就看得到。

08
安全與授權

裝之前看一眼

  • 選用的 API key 會把資料送到第三方：填了以後，資料會送到 Firecrawl（網頁抓取）、Google（Places 要開 Google Cloud 帳單）、Meta、Replicate／OpenAI（生圖按次付費）。用不到就不要填。
  • plugin 安裝會掛 hook：會攔截每一次寫檔和跑指令，用途是防止寫錯客戶資料夾，純本機、不連網，但一般小店用不到，照「② 只裝 skill 的安全安裝步驟」只裝 skill 就好。
  • 它會自己更新參考檔：有些 skill 的參考資料過期時，會叫 AI 上網查、改寫 skill 自己的檔案。網頁內容可能混進奇怪的指令，看到它說要更新參考檔時，先看它改了什麼。
  • 客人個資不要貼進去：貼評論可以，但客人的電話、地址、訂單資料不要貼。
  • AI 寫的是草稿：評論回覆和貼文送出前自己看一遍，價格、營業時間、優惠內容一定要自己對過。
  • 專案 2026-11-16 才建立，作者在說明裡推自己的付費工具和顧問服務（有標明，不買也能用全部 skill）。安全掃描只能抓已知手法，不代表沒有風險。
  • 授權：MIT，可以商用，轉發 skill 檔案時要保留原作者的授權聲明。
